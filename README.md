# RealEstateHub 🏠

A simple **Real Estate Property Portal** built using HTML, CSS and JavaScript.

## Features

* Property search
* Property filtering
* Buy/Rent options
* Property details
* Add to favorites ❤️
* Dark mode 🌙
* Responsive design
* Contact form
* LocalStorage

## Technologies

* HTML5
* CSS3
* JavaScript
* GitHub Pages

## Pages

* Home
* Properties
* Property Details
* Favorites
